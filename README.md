# Smart-Pantry-Manager-Assignment
Innovative way to reduce food waste by recipe suggestions through a Java Android Application .
Chose SQLite because it is a fully functional database that allows me to organize the data logically into tables. It also does not required internet connection to work on the mobile app. It is lightweigh
and a great option for mobile devices because it does not have to run on independent background servers processes. It also gives capabilities to retrieve filter sort and manipulate stored data. It is
secure and private to my app and the database persists as long as the application stays installed.
